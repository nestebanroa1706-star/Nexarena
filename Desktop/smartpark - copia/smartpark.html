¿Qué es SmartPark?

SmartPark es un sistema web diseñado para gestionar y controlar de manera organizada los parqueaderos de unidades residenciales en Colombia.

Reemplaza el control manual por una herramienta digital que mejora la organización, reduce conflictos y facilita la administración de espacios vehiculares.

Misión: Brindar una solución digital eficiente y confiable para la administración de parqueaderos residenciales.

Visión: Convertirse en el sistema de referencia para la gestión de parqueaderos en conjuntos residenciales.

🏠

Registro y gestión completa de residentes y sus vehículos.

Requerimientos del Sistema

  • RF1. Registrar residentes de la unidad residencial.
  • RF2. Consultar información de los residentes.
  • RF3. Actualizar datos de residentes.
  • RF4. Eliminar residentes del sistema.
  • RF5. Registrar vehículos de residentes.
  • RF6. Asociar vehículos a residentes específicos.
  • RF7. Consultar vehículos registrados.
  • RF8. Actualizar datos de vehículos.
  • RF9. Eliminar vehículos del sistema.
  • RF10. Crear cupos de parqueadero.
  • RF11. Asignar cupos a residentes.
  • RF12. Mostrar estado libre/ocupado por cupo.
  • RF13. Consultar disponibilidad de cupos.
  • RF14. Registrar visitantes al conjunto.
  • RF15. Registrar ingreso de vehículos visitantes.
  • RF16. Registrar salida de visitantes.
  • RF17. Consultar visitantes activos en el conjunto.
  • RF18. Generar historial de uso de parqueaderos.
  • RF19. Búsquedas por placa o nombre de residente.
  • RF20. Acceso al sistema mediante usuario y contraseña.
  • RNF1. Sistema web accesible desde navegadores comunes.
  • RNF2. Interfaz sencilla y fácil de usar para administración.
  • RNF3. Seguridad mediante autenticación de usuarios.
  • RNF4. Almacenamiento en base de datos relacional MySQL.
  • RNF5. Consultas procesadas en menos de 3 segundos.
  • RNF6. Compatible con computadores de oficina estándar.
  • RNF7. Integridad y consistencia de los datos registrados.
  • RNF8. Permite realizar respaldo de la base de datos.
  • RNF9. Disponible en horarios administrativos requeridos.
  • RNF10. Escalabilidad básica para crecimiento futuro.
